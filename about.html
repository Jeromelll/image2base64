About Image2Base64

Image2Base64 (also shown as Base64Img) is a free developer utility for encoding images to Base64 / data URIs and decoding Base64 back to images.

Everything runs in the browser. There is no account, no upload pipeline, and no server-side processing of your files.

  • Encode: PNG, JPG/JPEG, SVG, WebP, GIF
  • Decode: Base64 / data URI → preview and download
  • Copy helpers: raw Base64, data URI, HTML <img>, CSS

Source / issues: github.com/Jeromelll/image2base64
