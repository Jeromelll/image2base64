When does iOS strip metadata — and when it doesn't

Apple gives you partial protection, and it depends entirely on the channel:

  • AirDrop & Messages: iOS 15+ offers "Options → Remove Location" in the share sheet. Location is handled, but other EXIF (device model, timestamps) may still travel.
  • Mail (as attachment): the file is attached as-is — full EXIF travels with it unless you use the same Options menu.
  • "Save to Files", cloud drives, third-party apps: the original bytes are copied, metadata included.
  • Sending "as document" in messengers: preserves everything.

The pattern: iOS protects the casual path and preserves the power-user path. A pre-cleaned file is the only version that behaves the same everywhere.

Using this tool on iOS, step by step

  1. Open this page in Safari (Chrome and Firefox cannot decode HEIC on iOS).

On a Mac, Safari handles HEIC the same way. Chrome or Firefox will re-encode HEIC shots to JPEG — that conversion is real (slight quality change, different container) and the tool labels it clearly when it happens. JPEG and PNG files are byte-identical in quality everywhere.

Turn off iPhone geotagging at the source

Cleaning fixes existing photos; this setting fixes future ones. Go to Settings → Privacy & Security → Location Services → Camera → Never. From then on, new shots carry no coordinates. Trade-off: the Photos app can no longer group your library by place, and some third-party camera apps lose location features. Check any photo afterwards with the EXIF viewer to confirm no GPS group appears.

Frequently asked questions

Does iPhone automatically remove metadata when sharing?

AirDrop/Messages offer per-share location removal; Mail attachments, Files, cloud drives and document-style sends preserve the full EXIF. A pre-cleaned file is safe on every channel.

Can this tool read HEIC photos?

In Safari, yes — natively. On desktop Chrome/Firefox HEIC is re-encoded to JPEG (labeled in the tool). JPEG/PNG files are untouched byte-for-byte.

How do I stop geotagging on iPhone?

Settings → Privacy & Security → Location Services → Camera → Never. New shots get no GPS block; old ones still need cleaning.

What's inside an iPhone photo's metadata?

GPS (if enabled), Apple's MakerNote with device info, timestamps, lens/exposure data, orientation, sometimes a thumbnail. Inspect any file with the EXIF viewer to see yours.

Is the photo uploaded?

No — the whole pipeline runs in Safari on your device.
